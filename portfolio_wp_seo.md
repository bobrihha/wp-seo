# AI Автопилот для WordPress: Автоматическое наполнение блога (WP-SEO Hub)

**Суть проекта:** 
Автономная система (SaaS-панель + демон), которая на «автопилоте» собирает контент из заданных источников (YouTube, RSS, Telegram), с помощью нейросетей превращает его в полноценные, SEO-оптимизированные статьи с уникальными иллюстрациями и автоматически публикует в платформу WordPress.

## 🎯 Какую проблему решает?
Владельцы сайтов на WordPress, вебмастера и контент-менеджеры тратят десятки часов в неделю на рутинные задачи: поиск информационных поводов, рерайт текстов, подбор картинок, расстановку SEO-тегов, мета-описаний (Title, Description) и ручную верстку постов. 

Данная система полностью автоматизирует этот процесс. Она устраняет человеческий фактор, работает без выходных и позволяет генерировать бесконечный поток качественного контента, который привлекает поисковый трафик на сайт.

## ⚙️ Основной функционал (Как это работает)

* **Мульти-источниковый парсер контента:**
  Система умеет автоматически извлекать сырые данные (информационные поводы) из:
  * *YouTube-видео* (захват транскрибаций и субтитров).
  * *RSS-лент* новостных и тематических сайтов.
  * *Telegram-каналов* (парсинг сообщений через Telegram Telethon).
* **Генерация глубоких SEO-статей:** Разрозненный исходный материал превращается в структурированный лонгрид. Подключенные LLM-модели (OpenAI / Perplexity) формируют логическую структуру, пишут текст, прописывают правильные заголовки (H1-H3), мета-теги для плагинов (Focus Keyword, Meta Description, Title) и оформляют все в готовую HTML-верстку с чистым кодом.
* **Арт-дирекшн и генерация уникальных обложек:** Никаких заезженных стоковых фотографий. Встроенный модуль на базе *Google Vertex Imagen* или *DALL-E* анализирует смысл статьи, формулирует промпт для нейросети-художника и генерирует уникальную обложку (Thumbnail).
* **Прямая публикация в WordPress:** Взаимодействие с сайтом происходит прозрачно через WordPress REST API. Статьи могут публиковаться сразу (Live) или сохраняться как черновики для финальной вычитки редактором. В рамках проекта был написан кастомный PHP-плагин для корректной интеграции REST API с Yoast SEO.
* **Режим "Автопилота":** Для 100% автоматизации система имеет фоновый процесс (демон). Он по заданному расписанию проверяет источники, формирует очередь публикаций и постит на сайт. Встроенная SQLite база данных хранит историю, чтобы не допустить дублирования новостей.
* **Графический интерфейс:** Управление всей системой, добавление источников (ссылок) и настройка промптов происходят в интуитивно понятной UI-панели (Dashboard), без необходимости лезть в код или использовать терминал.

## 🛠 Технический стек и Архитектура
* **Backend:** Python 3.x
* **Пользовательский интерфейс:** Streamlit
* **Инфраструктура:** Docker Compose (система разворачивается 1 командой на любом VPS/VDS сервере)
* **База данных:** SQLite
* **API и Интеграции:** WordPress REST API, Telegram API (Telethon)
* **Нейросети:** OpenAI API, Google Vertex AI (Imagen) для фото
* **Специфика WP:** Разработан кастомный PHP-плагин `seo-rest-enable.php` и собственная дизайн-система CSS-классов под верстку AI-блоков.

## 📈 Результат для бизнеса (Value)
* **Снижение костов:** Бот заменяет труд целого отдела: контент-менеджера, копирайтера и SEO-специалиста.
* **Стабильность:** Блог регулярно обновляется по расписанию 24/7, без отпусков и больничных.
* **Рост органического трафика:** Правильная SEO-структура, регулярность постинга и уникальные изображения положительно ранжируются алгоритмами Google и Yandex.
* **Масштабируемость:** Архитектура позволяет поддерживать работу одновременно с десятками контентных сайтов.
